Is the race decided on Saturday?

A data analysis of every Formula 1 Grand Prix, 1950–2025

Orkida · Isela · Gjergj · Dion — source code on GitHub · Shqip

1. The question

A Formula 1 weekend has two parts. On Saturday, qualifying decides the starting order: the fastest driver starts first (pole position), the second fastest behind them, and so on. On Sunday, the actual race is run on the same circuit. Commentators often claim that the starting order decides the result — most famously at Monaco: “Overtaking is impossible here. The race was decided yesterday afternoon.”

We wanted to check how true this is. So we did not watch any races. We collected the results of every Grand Prix from 1950 to 2025 — 1,138 races on 78 circuits — and measured what a starting position is actually worth.

2. The data

We used two sources:

  • The Jolpica F1 API — every race result: starting position, finishing position, driver, and team.
  • Wikipedia’s list of F1 circuits — what the API does not know about each track: whether it is a street circuit or purpose-built, its length, and whether it is still in use.

3. Cleaning the data

The raw download had 26,313 rows. We removed three groups that do not fit the question, leaving 25,201:

4. A bug we caught (and how)

Our first cleaning rule removed every race held at the Indianapolis circuit:

rows = [r for r in rows if r["circuit_id"] != "indianapolis"]  # wrong

It looked reasonable — but the same circuit also hosted the United States Grand Prix from 2000 to 2007, which are real F1 races. We found the mistake with a simple sanity check: counting Michael Schumacher’s career wins. Our data said 86. The record books say 91. The five missing wins were exactly his five US Grand Prix victories at Indianapolis. The fix was to filter by race name instead of circuit:

rows = [r for r in rows if r["race_name"] != "Indianapolis 500"]  # correct

Lesson learned: always check your output against facts you already know.

5. Joining the two sources

To ask questions like “is pole worth more on street circuits?”, we had to connect the API results with Wikipedia’s circuit table. The problem: the two sources name the same circuits differently. Examples:

Autodromo Enzo e Dino FerrariAutodromo Internazionale Enzo e Dino Ferrarione word
Las Vegas Street CircuitCaesars Palace Grand Prix Circuita different name entirely

After normalizing the names, 61 of the 78 circuits matched automatically; the remaining 17 we matched by hand. Our join script stops with an error unless every circuit matches exactly once — a loud failure is better than a silently wrong answer.

6. Results

Finding 1 — what a grid slot is worth. Starting from pole, a driver wins 43.1% of races and finishes on the podium 64.1% of the time. From tenth place, the win rate is about 1%.

Finding 2 — Saturday matters more than ever. In the 1950s, pole converted to a win about 40% of the time. In the 1980s it fell to 28% — turbo engines failed constantly and race leaders often retired. Since 2000 it has stayed above 50%, and in the 2020s it is 55%: modern cars rarely break down, and the leader is hard to pass.

Finding 3 — the Monaco myth, tested. This is where the join pays off, because only the joined data knows each circuit’s type. On street circuits pole converts at 45.4%, on purpose-built circuits at 42.6%, and on old public-road circuits at 39.5%. Monaco itself: 46%, against 43% everywhere else. The commentators are right in direction — the walls do help — but they exaggerate the size: the difference is a few percentage points, not a guarantee.

7. Conclusion

Yes — about 43% of races are decided on Saturday, and the share is rising decade by decade.

One clarification: we measured the value of the actual starting slot, not raw qualifying speed. If a driver takes a grid penalty and drops five places, we count where they really started — on purpose, because the starting slot is what decides Sunday.

8. How it was built

The whole analysis is reproducible from four Python scripts, run in order:

  • collect_data.py — downloads results from the API and scrapes the Wikipedia table (Dion)
  • clean_data.py — filters the 26,313 raw rows down to 25,201 (Dion)
  • join_circuits.py — matches the 78 circuits across both sources (Orkida)
  • analyze.py — computes the grid-slot statistics and pole conversion (Isela)
  • plot.py — draws the three figures above (Gjergj)

Each member worked on their own branch and merged through a pull request, so every contribution is visible in the repository history.

Data: Jolpica F1 API (Ergast-compatible) and Wikipedia, “List of Formula One circuits”. All figures computed from 25,201 race results, 1950–2025.
